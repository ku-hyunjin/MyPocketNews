# MyPocketNews

## English

MyPocketNews is a native Android news application designed to connect with an external news API and present current stories in a clean, easy-to-read feed. This project aims to cover the complete process of building an API-driven Android app, from creating the user interface and displaying news articles to handling network responses, loading states, and errors.

## 日本語

MyPocketNewsは、外部のニュースAPIと連携し、最新の記事を見やすいフィード形式で表示するネイティブAndroidニュースアプリです。このプロジェクトでは、ユーザーインターフェースの作成やニュース記事の表示から、ネットワークレスポンス、ローディング状態、エラー処理まで、APIを利用したAndroidアプリ開発の一連の流れを実装することを目指しています。

## 한국어

MyPocketNews는 외부 뉴스 API를 연동하여 최신 기사를 깔끔하고 읽기 쉬운 피드 형태로 보여주는 네이티브 Android 뉴스 앱입니다. 이 프로젝트는 사용자 인터페이스와 뉴스 기사를 표시하는 단계부터 네트워크 응답, 로딩 상태, 오류 처리까지 API 기반 Android 앱 개발의 전체 과정을 구현하는 것을 목표로 합니다.
